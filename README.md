
# 🌍 Global Labor Market Dynamics (1991–2025)
### Data Analytics Portfolio Project | Microsoft Excel

---

## 📌 Project Summary

A comprehensive analysis of global unemployment trends across **189 countries** and **35 years** (1991–2025), built entirely in Microsoft Excel. This project examines unemployment cycles, gender employment gaps, youth labour disparities, and the impact of major economic crises including the 2008 Global Financial Crisis and the COVID-19 pandemic.

---

## 🛠️ Tools & Technologies

| Tool | Usage |
|------|-------|
| Microsoft Excel | Data cleaning, PivotTables, Dashboard, Charts, Map |
| ILO via Kaggle | Dataset source (57,519 rows, 189 countries) |

---

## 📊 Dashboard Features

- **5 KPI Cards** — Global avg unemployment, peak year, best year, youth gap, gender gap
- **7 Interactive Charts** — Trend line, country rankings, crisis comparisons, gender gap by decade
- **3 Slicers** — Filter by Age, Region, and Year simultaneously
- **Filled World Map** — Geographic unemployment visualization by country
- **Conditional Formatting** — Data bars and color scales for rapid pattern recognition

---

## 🔑 Key Findings

| Insight | Value |
|---------|-------|
| Global Average Unemployment (1991–2025) | 8.0% |
| Highest Country Average | South Africa — 33.5% |
| Lowest Country Average | Bahrain — 0.1% |
| Youth vs Adult Unemployment Gap | 10.6 percentage points |
| Gender Employment Gap (Global) | 21.4 percentage points |
| Worst Crisis Year | 2008 GFC & 2020 COVID-19 |
